# Расходы студента

Веб-приложение для учёта личных расходов студента. Пользователь может добавлять траты, указывая сумму, категорию и дату, после чего приложение автоматически показывает общую сумму расходов за выбранный месяц и разбивку расходов по категориям.

## Проблема

Студенту важно понимать, куда уходят его деньги в течение месяца. При ведении расходов вручную сложно быстро определить общую сумму трат и основные категории расходов.

## Решение

Приложение позволяет быстро добавлять ежедневные расходы и автоматически рассчитывает статистику за выбранный месяц.

## Реализованный функционал

- Добавление расхода:
  - сумма в тенге;
  - категория;
  - дата;
  - необязательное описание.
- Валидация введённых данных.
- Просмотр общей суммы расходов за месяц.
- Просмотр количества расходов.
- Разбивка расходов по категориям.
- Отображение доли каждой категории в процентах.
- Просмотр списка расходов.
- Удаление расхода.
- Восстановление последнего удалённого расхода.
- Переключение между месяцами.
- Автоматическое сохранение записей в браузере.
- Тестовый пример расходов для быстрой проверки приложения.

Суммы обрабатываются в целых тиынах, что позволяет избежать ошибок округления при расчётах. fileciteturn1file0

## Пользовательский сценарий

1. Пользователь открывает приложение.
2. Выбирает сумму расхода.
3. Выбирает категорию.
4. Указывает дату.
5. При необходимости добавляет описание.
6. Нажимает **«Добавить расход»**.
7. Расход появляется в списке.
8. Общая сумма и статистика по категориям обновляются автоматически.
9. Пользователь может перейти на другой месяц и посмотреть его расходы.
10. При необходимости расход можно удалить и восстановить.

Форма приложения содержит поля суммы, категории, даты и необязательного описания. fileciteturn1file4

Данные расходов сохраняются локально в браузере пользователя.

Серверная база данных и авторизация в текущей версии не используются. Данные не синхронизируются между разными устройствами. Также приложение не подключено к банковским системам. fileciteturn1file2

## Проверка работы

Для проверки основного сценария:

1. Открыть приложение.
2. Добавить расход, например:
   - сумма: `1500 ₸`;
   - категория: `Еда`;
   - дата: текущая дата;
   - описание: `Обед`.
3. Нажать **«Добавить расход»**.
4. Проверить появление записи в списке.
5. Проверить изменение общей суммы.
6. Проверить появление категории в статистике.
7. Добавить несколько расходов разных категорий.
8. Проверить, что суммы по категориям соответствуют общему итогу.
9. Удалить расход и проверить возможность его восстановления.

В приложении также предусмотрена кнопка заполнения проверочного примера с несколькими расходами. fileciteturn1file3
